EVM3588 相机控制台 1.2.2（Windows x64）
=====================================

把整个文件夹解压到电脑，双击 EVM3588CameraConsole.exe。
请保留 _internal/、ffmpeg/ 与 EXE 的相对位置，无需安装 Python。

在右侧“设备连接”填写板子地址、用户名、SSH 密码或密钥，点击连接。
默认板子 IP 为 192.168.2.221，用户名 root，SSH 端口 22。
首次连接需要核对主机指纹。密码可选择存入 Windows 凭据管理器。
连接后软件读取现有直播，不会自动启动第二条摄像头管线。

底部按钮控制直播、截图与录像；编码设置支持 H.264/H.265、宽高、帧率、码率、GOP。
截图自动下载。录像在板端保存，停止后可在“媒体文件”下载或勾选自动下载。
打开最近下载的 MP4 会在软件内回放。HDMI 按钮控制开发板显示屏。
关闭软件只关闭电脑端连接与预览，开发板直播和录像继续运行。

性能监测首屏显示：本订阅流速、网口总带宽占用、两端 CPU/内存、电脑解码与绘制帧率。
“占链路”与“网口总 TX 占用”分别表示当前订阅与整块网口，避免把多路流量混算。
趋势图、完整指标和 CSV 路径按按钮展开。时间刻度在图框外，横轴最多保留十分钟。
拖动中间分栏可调节预览和参数面板宽度；小屏或较大缩放时可以滚动访问下面的控件。

板端需已安装本项目 FFmpeg 环境与 avctl.py；本软件不会刷机或自动构建板端运行库。
详细图文说明：项目 docs/guides/Windows_相机控制台操作指南.md。
个人配置、日志和主机指纹保存在 %LOCALAPPDATA%\EVM3588CameraConsole\。
录像、密码、私钥和运行记录不上传 GitHub。

1.2.2：可拖动预览/设置分栏；窄窗口自动换行，小屏可滚动访问全部按钮。
长路径可完整换行与复制；预览减少两次整帧拷贝，保持原始宽高比和真实绘制计数。
匹配板端补丁后显示实际采集缓冲数、归还耗时峰值与采集时间戳年龄峰值。
保留 4 个软件解码线程，避免 low_delay 禁用帧级并行；区分模式可用和完整验收。
保留“性能监测”页、实测帧率/带宽、十分钟趋势、自动 CSV。
“性能 60 fps”最大 1280 宽；完整源流先解码再缩放，30 fps 源不会补成 60。
板端 HDMI 使用 VPU 硬解与 RGA，需部署匹配的板端程序及采集补丁。
已适配的实验内核可用真实相机 4K60；原固件仍只有 20/30 fps。
软件读取实际模式；完整验收记录还须与本机 boot、运行内核和 DT 匹配，不能仅凭枚举标为通过。
CSV 默认在用户数据目录 performance/，可在软件内改目录或导出，不记录凭据。
旧版与新版分别解压到新目录；软件不会刷写实验内核。
