EVM3588 相机控制台 1.1.0（Windows x64）
=====================================

把整个文件夹解压到电脑，双击 EVM3588CameraConsole.exe。
请保留 _internal/、ffmpeg/ 与 EXE 的相对位置，无需安装 Python。

在右侧“设备连接”填写板子地址、用户名、SSH 密码或密钥，点击连接。
默认板子 IP 为 192.168.2.221，用户名 root，SSH 端口 22。
首次连接需要核对主机指纹。密码可选择存入 Windows 凭据管理器。
连接后软件读取现有直播，不会自动启动第二条摄像头管线。

底部按钮控制直播、截图与录像；编码设置支持 H.264/H.265、宽高、帧率、码率、GOP。
截图自动下载。录像在板端保存，停止后可在“媒体文件”下载或勾选自动下载。
打开最近下载的 MP4 会在软件内回放。HDMI 按钮控制开发板显示屏。
关闭软件只关闭电脑端连接与预览，开发板直播和录像继续运行。

板端需已安装本项目 FFmpeg 环境与 avctl.py；本软件不会刷机或自动构建板端运行库。
详细图文说明：项目 docs/guides/Windows_相机控制台操作指南.md。
个人配置、日志和主机指纹保存在 %LOCALAPPDATA%\EVM3588CameraConsole\。
录像、密码、私钥和运行记录不上传 GitHub。

1.1.0：画面右上角选择流畅/均衡/清晰，只改变电脑预览。
新增解码与显示帧率、重连统计、下载 SHA-256 校验、异步退出与批量日志。
旧版与新版请分别解压到新目录，板端无需重新部署。
