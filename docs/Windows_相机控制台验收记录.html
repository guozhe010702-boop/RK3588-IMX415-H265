2. 发现并修正的问题

Windows RTSP 解码参数修正为本机构建支持的 -timeout。界面完成深色滚动区域、禁用按钮与缩放检查。

重复启停期间曾出现采集打开后没有首帧，重新启动还观察到驱动时间戳跳变导致补帧。控制器增加 STREAMOFF 后 0.5 秒等待、首帧失败的一次受限重试，并按帧序号生成固定帧率输出时间戳，禁止 FFmpeg 额外复制帧。修正后重新执行十次启停及持续测试。

应用参数失败会恢复旧配置与直播，返回恢复结果；实际尺寸不符会明确失败。下载时检查路径与文件类型，使用受限 SFTP 预取，避免大文件无界预取；下载进度使用可容纳大文件大小的字段。

自动下载仅针对本次结束的录像，停止未录像的直播不会反复下载上一段 MP4。停止直播中的录像封口失败会显示错误。
